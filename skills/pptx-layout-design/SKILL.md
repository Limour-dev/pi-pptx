# 版面规则：先量模板，再定常量

## 先量，不要猜

- 画布与页边距来自模板：`ppt_inspect(<模板>, mode="full", slides="1-3")` 里每个形状都有 `box_in`。
  把样例页正文的左边写成 `CX`、可写宽度写成 `CW`、正文首行 y 写成 `BODY_Y`，之后全本只用这三个常量。
- 版式自带的东西（logo、页脚线、底色）在 `ppt_inspect` 里标 `inherited: true`：它们已经在了，不要再画一遍，也不要去改版式/母版。
- 一页只放一个主张。标题（28–40pt）+ kicker（11.5pt 大写/加字距）+ 正文（13–16pt）+ 注释（10.5pt）就够四级；
  不要在同一页出现 5 种字号。

## 高度：唯一的公式

```
文字高度 ≈ 0.10 + 行数 × 字号 × 1.35 / 72      （单位 in）
```

- 12pt 一行 ≈ 0.28 in，13pt 三行 ≈ 0.87 in，40pt 一行 ≈ 0.85 in。
- 卡片/色块/形状**不会**因为文字变多而长高；`add_text` 省略 `h` 时才会 grow（spAutoFit），
  但 grow 会盖住下面的东西，生产脚本里宁可显式给 `h`。
- 表格高度必须自己算：`h = header_height + row_height × (rows - 1)`，并让包装函数返回底边，
  下一个块从 `bottom + 0.2` 开始。这是最常见的压字来源。
- 行宽留 5–10%：`ppt_doctor`/`ppt_inspect` 的 `font_substitutions` 说明渲染字体与 PowerPoint 字体不同，
  替换字面宽约 +5%。`text_fit.fits: true` 但 `slack_in < 0.1` 的框，实际渲染仍可能换行。

## 尺寸约定（16:9，13.33×7.5 in 时）

| 元素 | 尺寸 |
|---|---|
| 页边距 | 0.6–0.9 in；左右对齐同一条 `CX` |
| 正文行距 | 1.25–1.4（默认 1.35），段后 4–8pt |
| 卡片 | 3.7×2.1 in，三张 + 0.3 gap ≈ 11.97 宽；圆角 0.06–0.10，细边 0.75pt，无阴影 |
| 强调条 | 0.9–1.6 宽 × 0.05 高，放在标题下或正文上沿 -0.12 |
| 表格 | 列宽之和 = `w`；正文行高 0.30–0.36，表头 0.42–0.48；字号 10.5–11.5 |
| 图片 | 只给 `w`（等比缩放）；图注 10.5pt 放在图下 0.1–0.15 |
| 页码/脚注 | 10–10.5pt，弱色（如 `#5B6B7C`） |

数字和单位要一致：全文统一"英寸"和 0–1 位小数（`0.68`、`1.84`），不要在脚本里混用 pt 和 in。

## 页面类型与节奏

一本 deck 不是 10 页同样的卡片。交替使用：

- 封面/章节页：大字号 + 一句副标题 + 色条，大量留白。
- 三个数字/三张卡片：横向等分，数字 32–40pt 强调色，说明 11pt 弱色。
- 表格页：表格占 7–8 in 宽，右侧留一列卡片写"结论"，表格下留图注。
- 图 + 文：图 5–6 in 宽，说明在另一侧 4–5 in，顶部对齐。
- 纯观点页：一行 24–28pt 论断 + 一段 13pt 支撑，别塞卡片。
- 讨论/结尾：2–3 个真问题，不要"谢谢"收尾。

每页都要有讲者备注（`set_notes`）：一句"这页只讲什么"。删过模板页后跑 `notes_check` 防整体错位。

## 文案

- 正文一行不超过 ~40 个汉字（13pt × 6 in 宽）；超了就拆段或缩短，不要缩字号。
- 表格单元格 8–14 字；列宽先按"最长的 3 个值"定，再校验总和 = `w`。
- 术语、缩写、数字格式全本统一；成品用 `ppt_inspect(mode="text")` 通读校对，而不是回读脚本。
- 20+ 个同类元素（卡片/表格行/图标）用数据列表 + 循环生成，不要手写 20 遍。

## 常见错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 卡片里的字压到下一张卡片 | 卡片 `h` 是拍脑袋的，文字按 grow 溢出 | 用高度公式算 `h`，或缩小字号/减字 |
| 表格下面图注压在表格上 | 表格 `h` 小于实际行高之和 | `h = head_h + row_h × (rows-1)`，返回底边 |
| 中文换行位置和 PowerPoint 不一样 | 字体替换（字宽 +5%） | 行宽留 5–10%，重要标题不要顶满 |
| 新页左侧多一个圆点 | 版式自带空内容占位符 | `delete_shape` 删掉，不要 `set_text(" ")` |
| 整本看下来每页都一样 | 只用了一种页面模板 | 按上面的页面类型交替 |
